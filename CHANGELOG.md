# 1.5.0

- Added Note module (`/notes`) to help staff members adding info about players.
- Added `/serverstat` to show basic statistics about the server, such as TPS and memory usage.
- Improved how addons are loaded into Solstice.
- Improved how player data is handled.
- Added Jail module as a moderation tool to jail players when they misbehave.
- Fixed `/invsee` targeting source player instead of target player.
- Fixed all utility module commands (`/workbench`, `/anvil`, ...) to behave correctly when closed with items inside.
- Added long time span formatting.
- Added filter to `/hat`, it can act as either a whitelist or a blacklist.
- Fixed issue with LuckPerms crashing when attempting to get the display name of a fake player.
- Fixed `/sethome` using the wrong command in `[Force]` button.
- Added `/kits` command, it opens a GUI to claim a kit.
- Added PowerTool module to bind commands to items when using them.
- Other bug fixes and improvements.
